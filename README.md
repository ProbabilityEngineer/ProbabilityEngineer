---

EDHM-UI for Mac is a port of [BlueMysticals EDHM-UI](https://github.com/BlueMystical/EDHM_UI) ui modifier for the windows spaceship game Elite Dangerous, for those of us cursed with running Elite on our macs through crossover or wine. I keep it up with upstream releases when the game is updated.

ScanTailor Advanced for Mac is my port of scanner deskewing package from [ScanTailor Advanced](https://github.com/ScanTailor-Advanced/scantailor-advanced)

I also have an extensive collection of Pi extensions, including the [Pi-Diet](https://github.com/ProbabilityEngineer/pi-diet) family for trimming Pi's context, saving tokens and and keeping agents attention focussed on the task at hand, not polluted with spamming tools, etc.
