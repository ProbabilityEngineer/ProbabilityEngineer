EDHM-UI for Mac is a port of [BlueMystical's EDHM_UI](https://github.com/BlueMystical/EDHM_UI) ui modifier for the windows spaceship game Elite Dangerous, for those of us cursed with running Elite on our macs through crossover or wine. I keep it up with upstream releases when the game is updated. (GPL 3.0)

Elite Dangerous Crossover HiDPI Fix is a simply windows registry file that forces Elite to be HiDPI aware, allowing borderless mode to output the screen's resolution, not the desktop's scaled logical resolution (defaults at x0.5 on mac). The advantage of this is that borderless mode is *much* more reliable for app-switching than fullscreen mode

ED-Unofficial-Patch-Mac provides metalfx native antialiasing, (It will break you like feeding a dog bacon. Now I've seen it, I can't play the game without it.) superscaling, star-colored lighting is back, and various fixes. Based on [ED-Unoffical-Patch](https://github.com/characterecho-sean/ed-unofficial-patch) so [give them your $$$](https://ko-fi.com/seancharacterecho).

DXMT is a build of dxmt for ED-UP-Mac, with fixes for memory safety and glass decal alphas. It's optional, there are workarounds in ED-UP-Mac (you won't notice the difference with decal alphas, without this switching resolutions and superscaling ratio can boot you from metalfx to fsr 3 aa), and installing this will affect all of your crossover bottles. Updating Crossover will revert this to crossover's stock version. It is unsupported.

ScanTailor Advanced for Mac is my port of the scanner deskewing package from [ScanTailor Advanced](https://github.com/ScanTailor-Advanced/scantailor-advanced) (GPL 3.0)
